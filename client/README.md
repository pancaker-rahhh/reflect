# Reflect Client

React + TypeScript frontend for the Reflect feedback management system.

## Setup

```bash
# Install dependencies
npm install

# Initialize MSW
npx msw init public/ --save

# Start development server
npm run dev
```

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- React Router v6
- TanStack Query
- Zustand
- MSW for API mocking
