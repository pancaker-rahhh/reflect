🚀 CDN Widget System Test

✅ Testing New CDN Architecture

This page tests the new CDN-based widget loading system with:

  • Dynamic loader script from CDN server (port 3001)
  • Proper configuration fetching
  • Widget versioning support
  • Cache-friendly serving

📝 How it works:

  1. The loader script is fetched from the CDN server
  2. It reads widget configuration from data attributes
  3. Fetches widget config from API via CDN proxy
  4. Dynamically loads the appropriate widget version
  5. Renders the widget with proper error handling
Embed Code Used:
<script
  defer
  src="http://localhost:3001/cdn/loader.js"
  data-widget-id="test-widget-key-123"
  data-theme="light"
  data-position="bottom-right"
></script>

Expected Behavior: The widget should load from the CDN server and display in the bottom-right corner with all features working.

Check the browser console for loader messages and widget status.
